# ERCRef.github.io
Official website for the ERCRef project

The homepage (`index.html`) is the EIP/ERC citation graph. It is generated: edit
`tools/citation-graph/template.html` and run `tools/citation-graph/build.sh`.
See [tools/citation-graph/README.md](tools/citation-graph/README.md).
The previous landing page is `about.html`.
